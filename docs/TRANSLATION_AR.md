# الترجمة المحلية

يخزّن TaskBoard كل عنوان ووصف كزوج لغوي (`{ en, ar }`). تعرض النماذج حقلاً
واحداً بلغة الواجهة الحالية، وتملأ اللغة الأخرى تلقائياً عبر ترجمة آليّة تعمل
بالكامل على المعالج المحلي. لا يغادر أي نص الجهاز ولا تُستخدم أي خدمة ترجمة
سحابية.

## كيف يعمل

1. يعرض النموذج حقلاً واحداً بلغة الواجهة الحالية.
2. عند الحفظ، يفحص العميل نوع الكتابة (عربي/لاتيني).
3. إذا لزمت الترجمة، يستدعي العميل `POST /api/translate`.
4. يترجم الخادم بموديل ONNX محلي ويعيد النص.
5. يخزّن العميل `{ en, ar }` ثم يرسل الكيان.

إذا فشل طلب الترجمة، يُخزَّن النص المكتوب في اللغتين ويظل الحفظ ناجحاً.

## قاعدة اللغة

| لغة الواجهة | النص المكتوب | النتيجة                               |
| ----------- | ------------ | ------------------------------------- |
| عربي        | عربي         | `ar` = المكتوب، `en` = مُترجم (ar→en) |
| عربي        | لاتيني       | `ar` = المكتوب، `en` = كما هو         |
| إنجليزي     | لاتيني       | `en` = المكتوب، `ar` = مُترجم (en→ar) |
| إنجليزي     | عربي         | `en` = المكتوب، `ar` = كما هو         |

النص المختلط المتوازن يُخزَّن كما هو. تُتجاهل الأرقام وعلامات الترقيم والروابط
وأسماء العلامات المفردة عند تحديد الكتابة السائدة.

## النص المنسّق

أوصاف المهام نص منسّق. تُترجم عُقد النص فقط؛ ويُحفظ التنسيق الغامق والمائل
والقوائم والروابط والمحاذاة. لا يُترجم النص داخل `code` و`pre` و`script`
و`style`.

## الموديل

- **المحرك**: `Xenova/nllb-200-distilled-600M` (ONNX، int8) عبر
  `@huggingface/transformers`.
- **التشغيل**: Node.js (على المعالج فقط)، يُحمَّل مرة ويُخزَّن في الذاكرة.
- **الاتجاه**: يُضبط عبر أكواد FLORES-200 في `translation.config.json`.
- **حجم التحميل**: نحو 900 ميغابايت، في مجلد `models/` (مُستثنى من git).

## الإعداد

```bash
npm install
npm run models:download
```

يخزّن `npm run models:download` الموديل في `models/`. عند التشغيل يقرأ التطبيق
من القرص فقط (`allowRemoteModels` معطّل)، فيعمل دون إنترنت.

## الإعدادات

| المتغير                  | الافتراضي  | الوصف                |
| ------------------------ | ---------- | -------------------- |
| `TRANSLATION_ENABLED`    | `true`     | تعطيل الترجمة كلياً. |
| `TRANSLATION_MODELS_DIR` | `./models` | مجلد موديل ONNX.     |

معرّف الموديل والتكميم وأكواد اللغة في `translation.config.json` حتى لا
يختلف المُحمِّل عن وقت التشغيل.

## الواجهة البرمجية

`POST /api/translate` (يتطلب مصادقة ومحدّد معدّل)

```json
{ "segments": ["نص"], "from": "ar", "to": "en" }
```

الاستجابة:

```json
{ "translations": ["translated text"] }
```

يعيد `503` مع `code: "translation_unavailable"` عند غياب الموديل أو تعطيل
الترجمة؛ وعندها يخزّن العميل النص كما هو.
